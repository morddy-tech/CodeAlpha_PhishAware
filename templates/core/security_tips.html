Security tips

Practical, defensive habits you can apply today.

{% include "includes/svg.html" with name="key" %}

Password hygiene

  • Use a unique, long passphrase for every account.
  • Let a password manager generate and store passwords.
  • Never reuse passwords across sites.
  • Never share your password with anyone, even IT support.
{% include "includes/svg.html" with name="lock" %}

Multi-factor authentication

  • Enable MFA on email, banking, and social media first.
  • Prefer authenticator apps or hardware keys over SMS.
  • Never read a one-time code back to a caller.
{% include "includes/svg.html" with name="eye" %}

Suspicious links

  • Hover links to inspect the real domain before clicking.
  • Type official addresses yourself instead of using links in messages.
  • A padlock (HTTPS) proves encryption, not trustworthiness.
{% include "includes/svg.html" with name="users" %}

Social engineering

  • Verify unusual requests out of band (a known phone number).
  • Never approve payments or gift cards from email alone.
  • Urgency plus secrecy equals fraud.
{% include "includes/svg.html" with name="message-square" %}

Reporting suspicious messages

  • Use your organization's report-phishing button or forward to security.
  • Keep the message intact so it can be analyzed.
  • Reporting protects everyone, not just you.
{% include "includes/svg.html" with name="globe" %}

Safe browsing

  • Bookmark important sites and navigate from the bookmark.
  • Keep your browser and device updated.
  • Be wary of pages that threaten or rush you.
{% include "includes/svg.html" with name="info" %}
Remember: this platform is educational only. If you believe you've been phished, change your passwords, enable MFA, and report to your security team immediately.
